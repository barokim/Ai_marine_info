# 국립해양조사원 실제 API 연결 검증 결과

검증일: 2026-10-27 오전 10시경 KST

## 적용한 설정과 코드

- `.env`: 사용자가 제공한 공통 인증키를 `KHOA_API_KEY`에 설정했다. 두 화면의 키가 같아 공통 변수를 사용한다. 이 보고서에는 키를 기록하지 않는다.
- `.gitignore`: 기존 `.env` 제외 규칙을 확인했다. 소스·문서에 실제 인증키가 포함되지 않는지 검사해 통과했다.
- `services.py`: `python-dotenv`의 `load_dotenv(Path(__file__).resolve().with_name(".env"), override=False)`를 추가했다. 기존 코드는 환경 변수만 읽고 `.env`를 직접 로드하지 않아 파일에 입력해도 적용되지 않을 수 있었다. 지금은 실행 위치와 관계없이 프로젝트 파일을 읽으며, 이미 설정된 운영 환경 변수는 유지한다.
- `test_khoa_guides.py`: 다른 디렉터리에서 실행해도 `.env`를 읽는지, 외부 환경 변수가 파일보다 우선하는지 검증을 추가했다. 테스트는 실제 인증키 대신 별도 임시 파일의 테스트 키를 사용한다.

기존 `python-dotenv` 의존성을 사용해 패키지 추가는 없다. 화면의 Endpoint는 서비스 기본 주소다. 기존 코드에는 활용가이드에 따른 `/GetTideFcstHghLwApiService`, `/GetDTRecentApiService` 작업 경로가 이미 붙어 있어 유지했다.

## 실행·저장 검증

1. FastAPI TestClient에서 실제 외부 API를 연결해 세 지역의 `/api/dashboard`를 조회했다. 각 지역의 결과가 임시 SQLite에 저장되고 재조회 시 일치하는지 확인했다. 기존 개인 기록 DB와 분리해 검증했다.
2. Uvicorn을 `127.0.0.1:8001`에서 실제 실행했다. 홈페이지, `/docs`, `/static/app.js`가 HTTP 200이었다.
3. 실행 서버에 HTTP로 인천 대시보드를 요청해 조석·관측·해양 예보가 모두 `ok`인지 확인했다. 이 요청은 실제 앱 DB에도 이력을 저장했으며 이력 상세가 HTTP 200으로 열렸다.
4. 자동 테스트 26개와 JavaScript 구문 검사에 통과했다.

키가 없는 상태의 모의 응답 테스트와 달리, 이번 결과는 사용자가 제공한 키를 공식 KHOA 서버로 보내 받은 실제 데이터에 기반한다. 실행 환경의 기본 네트워크 제한 때문에 최초 시도는 연결되지 않았고, 외부 연결이 허용된 실행에서 정상 수신했다. 이 제한을 API 인증 실패로 판단하지 않았다.

기계 판독용 요약은 로컬 `data/khoa_live_verification_2026-10-27.json`에 저장했다. 인증키·전체 요청 URL은 포함하지 않는다. 이 파일은 시점별 검증 결과이며 실시간 자료가 아니다.

## 화면 열기와 재실행

검증 당시 서버 주소: <http://127.0.0.1:8001>

서버가 종료되었으면 아래와 같이 실행한다. `.env` 수정 후에는 서버를 다시 시작한다.

```powershell
Set-Location C:\KBR\sea_info_dashboard
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8001
```

이미 8001에서 서버가 실행 중이면 추가로 실행할 필요가 없다. 이번 실제 검증 범위는 해양 데이터 조회와 저장이며 사진 분석 API의 실제 인증·인식 검증은 포함하지 않는다. 브라우저의 시각적 배치 전체를 자동 검증한 것은 아니다.
