{% elif page == 'about' %}
우리 바다를 알아가는 정보 서비스
AI-marine info는 기존 Sea-Info 대시보드의 해양 조회·생물 검색 기능을 연결한 학습용 서비스입니다. 공공기관이 운영하는 공식 사이트가 아닙니다.
물때와 실측 자료는 국립해양조사원, 모델 예보는 Open-Meteo, 생물 분류는 MBRIS·WoRMS를 사용합니다. 데이터마다 관측 지점과 시각이 다르므로 출처와 시각을 함께 확인해 주세요.
물때는 현장 출입 가능 시간을 뜻하지 않으며 AI 사진 분석은 종 확정이나 식용 안전성 판정이 아닙니다.

{% elif page == 'privacy' %}
개인정보 안내 · 운영 전 검토용
이 문서는 학습용 안내 초안입니다. 공개 운영 전 운영자·연락처·보유기간·삭제 절차를 확정해야 합니다.
  • 이메일·비밀번호는 Supabase Auth가 처리하며 이름은 사용자 메타데이터에 저장합니다.
  • 게시글과 작성 당시 이름은 로그인 회원에게 공개됩니다.
  • 관찰 기록·조회 이력·분석 사진은 서버의 별도 SQLite에 회원별로 저장합니다.
  • 사진 분석은 동의 후 OpenAI에 전송하며 EXIF를 제거한 분석용 이미지를 저장합니다.
  • 브라우저 access token은 sessionStorage에 저장하며 로그아웃 시 제거합니다.
  • 관찰 기록과 조회 이력은 본인이 화면에서 삭제할 수 있습니다.
