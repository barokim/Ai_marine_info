# 전국 지역·관측소 데이터 안내

## 제공 범위

현재 목록은 **11개 시·도, 74개 해안 시·군·구, 113개 등록 관측·예보 지점**입니다. 물때 예보 지점만 있는 경우와 실측도 제공하는 경우를 구분합니다. 전국의 모든 API 지점을 전부 등록했다는 뜻은 아닙니다.

공식 가이드에서 추출한 원본 코드 목록은 조석 166개, 관측 54개입니다. 해당 가이드에 실린 코드·이름을 먼저 검증한 후 행정구역에 연결한 지점만 화면에 노출합니다. 코드 목록에 없는 이름을 추측해서 API에 보내지 않습니다.

## 파일별 역할

- `data/station_sources.json`: 로컬 공식 HWP 활용가이드의 코드·이름만 저장합니다. 문서 SHA-256과 파일명을 포함하며 예제 인증키는 추출하지 않습니다.
- `scripts/build_regions.py`: 시·도·시·군·구 목록, 대표 해역 좌표, 연결할 지점 이름을 관리합니다.
- `data/regions.json`: 런타임이 사용하는 최종 JSON입니다. `tides`, `observations`는 각 가이드의 코드 존재 여부로 정합니다.
- `app/regions.py`: ID 유효성·기존 3개 지역 별칭·다른 지역 선택 여부를 검사합니다.

공식 참고 페이지:

- [국립해양조사원 조석예보(고, 저조)](https://www.data.go.kr/data/15156018/openapi.do)
- [국립해양조사원 조위관측소 최신 관측데이터](https://www.data.go.kr/data/15155508/openapi.do)

코드 존재는 현재 API 이용 승인이나 현재 관측값 수신을 보증하지 않습니다. 실제 키를 사용한 지점별 호출은 이번 작업에서 실행하지 않았습니다.

## 대표 좌표의 의미

시·군·구마다 **모델 예보용 대표 해역 좌표**를 지정했습니다. 이것은 국립해양조사원 관측소의 측량 좌표나 행정구역 중심점이 아닙니다. Open-Meteo의 `cell_selection=sea`로 해양 격자를 요청합니다.

다른 지역 관측소를 선택해도 모델 예보는 원래 선택한 시·군·구 대표 해역을 유지합니다. 예를 들어 김포시에서 속초 지점을 선택하면 다음처럼 구분합니다.

```text
선택 지역: 경기도 김포시
물때·실측: 강원특별자치도 속초시 속초 지점 (다른 지역)
모델 예보: 김포 대표 해역
```

관측소가 없는 지역에 다른 도시의 관측값을 자동 대입하지 않습니다. 모델 예보만 보여주고, 사용자 선택으로 다른 지점을 조회할 수 있습니다. 관측소가 여러 개면 목록에서 선택합니다.

## 자료 없음과 오류

- 관측소 미등록: `no_data`, 지역 자료 없음 안내
- 조석 전용 지점: 물때만 조회, 실측 수온은 미제공
- API 키 없음: `not_configured`
- 제공자 장애·승인 오류: `error`
- 선택 날짜에 값이 없음: `no_data`
- 실측 항목 미제공: 숫자 대신 `—`
- 2시간 이상 지난 오늘 실측: 원본 서비스의 지연 안내 유지

기존 지역 쿼리 `region=incheon`, `region=busan`, `region=jeju`도 각각 기존 관측소로 연결됩니다. 신규 조회는 `city_id`, 선택적 `station_id`, `target_date`를 사용합니다. `p01` 같은 값은 이 앱의 내부 ID이며 공식 행정코드가 아닙니다.

## 지점 추가 방법

1. 공식 가이드에서 지점 코드·이름·지원 API를 확인합니다.
2. 지점의 실제 소재지를 확인하고 `build_regions.py`의 해당 시·군·구에 이름을 추가합니다.
3. 공식 가이드가 바뀌었다면 `extract_station_codes.py`로 코드·이름만 다시 추출합니다. 이 개발 보조 도구에는 `olefile`이 필요합니다.
4. `python scripts/build_regions.py`를 실행합니다. 가이드에 없는 이름은 제외 목록에 표시됩니다.
5. 테스트를 실행하고, 운영 전 실제 키로 반환된 지점 이름·날짜·자료 항목을 대조합니다.

`build_regions.py`는 나열 순서로 내부 ID를 만듭니다. 운영 후에는 기존 항목을 재정렬하거나 중간에 삽입하지 말고 새 지역을 끝에 추가하세요. 이미 저장된 관찰 기록과 선택 정보가 기존 ID를 참조합니다.
